# AI and TCS Workshop · FOCS 2026

Workshop website for November 8, 2026, 3:30–5:30 p.m. Eastern, at the Eisner & Lubin Auditorium, NYU Kimmel Center, New York City.

The program includes a one-hour keynote by Daniel Litt followed by a one-hour panel with Litt, Nikhil Srivastava, Barna Saha, Dan Spielman, and Pravesh Kothari.

The site is self-contained in `index.html`, with no build step or external asset dependencies. GitHub Pages serves the root of the `main` branch.
